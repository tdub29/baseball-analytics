## Residuals explained

- Trajectory mapping: none needed beyond the four direct pairs (ground_ball gb, line_drive ld, fly_ball fb, popup pu) and bunts to NA. StatsAPI shares sit within 0.1 point of Retrosheet 2025. Retrosheet gives a ball-in-play type to 127 plate appearances that are not balls in play (mostly strikeout double plays, coded hittype F); no ball in play exists, so StatsAPI has no trajectory, and downstream code reads bb_type only on balls in play. "empty" is StatsAPI's blank trajectory on catcher's interference.
- Per-batter totals: 20 plate appearances do not align one to one. On a mid-count pinch hitter the official scorer charges a strikeout or walk to the batter the count belongs to; Retrosheet follows that rule and StatsAPI names the batter at the plate.
- Parks: TOK01, TAM02, SAC01, BST01 first appear in 2025, so a map learned from 2021-2024 cannot know them. All are in the map used for the next season.
- Umpires: game-level misses are jascs901, an umpire Retrosheet coded differently before 2025; the map now takes the latest season's code. Per-PA misses in 10 games are mid-game umpire changes, which Retrosheet tracks per play and StatsAPI's game officials list does not.
- Start time: StatsAPI gives the scheduled time; Retrosheet the actual start when a delay or a doubleheader's second game moved it. No model input uses it (day or night is exact).
- Batter hand: Retrosheet's plays file gives the registered hand, B for switch hitters, as does StatsAPI's player record, except a handful of hitters the two register differently.
